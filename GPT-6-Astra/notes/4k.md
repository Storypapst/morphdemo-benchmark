# Phase Lock — 4,096 bytes

Build from the project root with `bash src/4k/build.sh`. Required tools are the
machine's GCC, GNU objcopy, patchelf and Python 3. The build links installed
SDL2, OpenGL, libm and libc by soname, removes the RPATH, and sets the payload
interpreter to `/lib64/ld-linux-x86-64.so.2`. No extra build packages are needed.

`src/4k/demo.c` synthesizes 48 kHz stereo float audio in SDL's audio callback
and runs the 60-second visual timeline. A 120 BPM pulse shapes both the kick
envelope and the rings. A rising minor arpeggio joins an initially sparse pad,
then the harmony settles on A at second 40 and the whole score fades during
seconds 55–60. Chord envelopes reach zero
at note changes. Escape and a window-close event exit through SDL_Quit.

`src/4k/scene.frag` raymarches a procedural luminous field. Unstable cyan
filaments gather into one ring, an amber second ring emerges during seconds
16–28, and a third during seconds 28–40. Distortion subsides into three
perpendicular resonant orbits by second 43. The generated five-by-five MORPH
lettering appears during seconds 46–50, followed by a fade to black at 60.
The fragment program is embedded at build time. The window requests
1920×1080 and uses the native fullscreen drawable on a scaled desktop.

`src/4k/pack.py` removes unused ELF section metadata and performs a deterministic
optimal LZSS parse. Each group has eight flag bits; literals cost one byte;
matches have a 12-bit backward distance and a four-bit length with an optional
extension. The build independently decodes the stream to verify it. A native
x86-64 unpacker is assembled using GCC and objcopy. It reconstructs the ELF
inside its own writable mapping, writes it to an anonymous memfd, and invokes
execveat with the original arguments and environment. This uses no shell,
external decompressor, on-disk extracted file, or other production program.
The outer executable is a native ELF with a single load segment. Zero padding
sets its exact size to 4,096 bytes.

The source includes all imagery, lettering and audio synthesis. There are no
production assets, filesystem content inputs, runtime downloads or external
renderer processes. Initial runtime validation, frame captures, audio metrics
and isolation tracing are managed by the project's verification harness.
